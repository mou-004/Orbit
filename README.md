ORBIT — Science Learning Platform
ORBIT is a game-inspired science learning platform for children, built with Next.js, React, and Tailwind CSS. It helps students explore Earth, the Moon, the Sun, the planets, the solar system, and stars through lessons and interactive activities.
Features
- English and Bangla language options
- Science lessons with review questions
- XP, ranks, and achievements
- Interactive learning tools and a searchable glossary
- Links to NASA resources for further reading
- A static orbital diagram
